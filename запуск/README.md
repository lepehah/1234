# Что запускать

Рабочая папка миссии. Остальное в `1234` — исходники и регламент, их запускать не нужно.

## Порядок

1. На ноутбуке: `python3 ui_server.py` → в браузере http://127.0.0.1:8080/
2. На сайте разметить деление (`-1`) и старты Д1/Д2 → **Скачать matrix.json**
3. `./push_mission.sh ~/Загрузки/matrix.json`
4. Два терминала — команды, которые напечатает `push_mission.sh`

## Файлы

| Файл | За что отвечает | Где крутится |
|---|---|---|
| `ui_server.py` | Поднимает сайт и принимает с дронов план, позицию, находки | ноутбук |
| `index-v2.html` | Сама панель: сетка 5×5, пути, маркеры, логи цветов | отдаёт `ui_server.py` |
| `push_mission.sh` | Копирует скрипты и `matrix.json` на оба OrangePi | ноутбук |
| `a8gem.py` | Полёт: взлёт, облёт своей зоны, поиск цветов | каждый дрон (`--drone 1` или `2`) |
| `plan_paths.py` | По `matrix.json` режет поле на две зоны и строит два маршрута | вызывается из `a8gem.py` |
| `ui_report.py` | Шлёт план/позицию/находки на панель по HTTP | вызывается из `a8gem.py` |
| `mission_log.py` | Пишет логи и traceback в `logs/` | все python-скрипты |
| `matrix.json` | Пример карты (скачанный с сайта клади сюда же или в `~/Загрузки`) | читает `a8gem.py` |
