### 1. SSH `Connection reset by peer` (первые пинги)

Плата рвала TCP на 22. Это не баг панели. В `start_flight.py` добавлен retry (2 повтора, пауза 1.5 с) на reset/refused.

### 2. Лог «не работает» — на самом деле работает

Цепочка живая:

- браузер POST `/api/test-log` 200
- SSH mkdir/scp/python дошли (`192.168.1.19 "POST /api/vision"` — **плата сама стукнулась в панель**)
- карточка на сайте уже была с текстом `ModuleNotFoundError`

Потом `ui_server` ещё раз писал «Пинг НЕ ПРОШЁЛ», потому что `drone_ping.py` возвращал код 1. Исправлено: если ошибка уже ушла на сайт через `/api/vision`, процесс выходит 0.

### 3. `No module named 'sverk_interfaces'`

SSH заходил на **хост** OrangePi и вызывал системный `python3`. Пакет Сверх живёт после `source .../setup.bash` или **внутри Docker `sverk_ros2`** (см. `comand.md`: «команды внутри контейнера sverk_ros2»).

Добавлен `run2/board_run.sh`:

1. source типичных `setup.bash` (humble/jazzy, `sverk_ws`, `ros2_ws`);
2. если импорта нет — `docker ps | grep sverk`, `docker cp` скриптов в `/tmp/sverk_mission`, `docker exec` с source и python3;
3. fallback: тот же python3 (ошибка будет явной).

`start_flight.py` теперь запускает:

```
board_run.sh drone_ping.py --drone N --ui http://НОУТ:8080
board_run.sh a8gem.py --drone N matrix.json --ui ...
```

а не голый `python3`.

### 4. Стоп exit 255

`pkill` / обрыв SSH. `_ssh(..., check=False)` на стопе; в конце remote `true`.

## Сайт: контракт API

База: `http://127.0.0.1:8080` (дроны бьют в `http://<IP ноута>:8080`).

- `GET /` — HTML
- `GET /api/state` — json: `live`, `matrix`, `drone1/2`, `route1/2`, `events[]`, `batteries`, `launch_status`, `launch_message`
- `POST /api/plan` — маршруты с платы
- `POST /api/telemetry` `{drone_id, x, y, battery?}`
- `POST /api/vision` `{drone_id, x, y, z, color, message, image_b64?}`
- `POST /api/start` `{matrix, drone1, drone2}` — фон: scp + a8gem
- `POST /api/kill` — pkill
- `POST /api/test-log` `{drone_id: 1|2}` — фон: ping

Цвета UI: `red|yellow|green|blue`. Русские имена мапит `ui_report.COLOR_TO_UI`.

## plan_paths

`plan_mission(matrix, drone1, drone2)`:

- `-1` = стена деления; ось по спану клеток (`y_span >= x_span` → вертикаль, left/right; иначе горизонталь, top = меньший y как на сайте);
- зоны строго по одну сторону координаты split, gap-клетки на линии — коридор, в покрытие не входят;
- назначение: min cost BFS до зоны (венгерская 2×2);
- транзит BFS по всем летабельным; второй ждёт на старте (`pad_for_transit`);
- змейка соседними клетками, без прыжков.

Тест: `python3 plan_paths.py --self-check` (на ноуте, без ROS).

## a8gem

`--drone {1,2} [--ui URL] [matrix.json]`

Камера: `drone.camera.read_numpy(encoding="rgb8")` — это курс-обёртка, в апстрим README чаще `drone.image.take_picture()`. Если ping/полёт упадут на `camera`, проверить API на конкретной прошивке.

`read_battery` смотрит `voltage|battery|batt_voltage` у telemetry; ping ещё `/fmu/out/battery_status`.
