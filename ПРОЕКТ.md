# Сверх.Рой — два дрона, деление поля, поиск цветов

Документ для человека и для следующего агента. Рабочая копия кода: `/home/lepehha/Загрузки/1234/run2/`. Старые копии `запуск/` и файлы в корне `1234/` не трогать, если нет нужды.

## Задача

Поле 5×5 меток ArUco. Эксперт делит его цветными листами (клетки `-1`). Два дрона COEX/Сверх на OrangePi + ROS 2 сами:

1. понимают, где деление (вдоль или поперёк);
2. берут каждый свою зону (ближайшую к старту);
3. если оба в одной зоне — один проходит в другую через разрыв в линии `-1`;
4. облетают зону змейкой, **не садясь на `-1`**;
5. ищут цветные квадраты (красный / жёлтый / зелёный) и отдают координаты.

Навигация по ArUco. SDK: `sverk_interfaces`. Регламент: `Регламент интенсива по роевому взаимодействию дронов, ТГУ.pdf`. Гайд UI: `saytik__tutor/sverh_roi_3_scripts_guide-v2.pdf`. Заметки по рою ESP-NOW: `comand.md`.

На платах Сверх Python-скрипты запускают так (документация `sverk_interfaces`):

```bash
cd ~/sverk_ws
source install/setup.bash
python3 ваш_скрипт.py
```

Часто это **внутри Docker `sverk_ros2`**. Системный `python3` на хосте **не видит** `sverk_interfaces`. Запуск с ноута идёт через `board_run.sh` (source ROS или `docker exec`).

В контейнере OpenCV собран под NumPy 1.x, а в `/usr/local` может лежать NumPy 2. Тогда `import cv2` падает. Фикс: `import numpy_fix` **первой строкой** (файл `numpy_fix.py` из 1234). Камера по доке: `drone.image.take_picture()` (BGR). Курс-обёртка `drone.camera.read_numpy` может отсутствовать — в run2 есть запасной путь.

В `comand.md` также фигурирует `ssh orangepi@ip -p 2222` / пароль `orangepi` и `nano sverk-ros2/.env` (`ENABLE_SWARM`, `SWARM_ID`). Для панели сейчас используется пользователь `sverk` порт 22.

SSH с ноутбука без пароля: ключ `~/.ssh/id_ed25519` (коммент `lepehha-sverk-mission`), `ssh-copy-id` на оба борта уже делали.

## Принцип работы (run2)

```
Браузер  →  ui_server.py :8080  →  SSH/scp  →  OrangePi
                ↑                              │
                └── HTTP /api/plan|telemetry|vision ← a8gem / drone_ping
```

1. На ноуте: `cd .../run2 && python3 ui_server.py`, браузер `http://127.0.0.1:8080/`.
2. На сетке: `-1` = деление (цветной лист), `1` = летать; маркеры Д1/Д2 = старты.
3. **Запуск полёта** → POST `/api/start` → `start_flight.py` пишет `matrix.json`, копирует скрипты в `/home/sverk/mission` на оба борта, стартует `board_run.sh a8gem.py --drone N ... --ui http://НОУТ:8080`.
4. На каждой плате `plan_paths.py` строит маршрут своей зоны; `a8gem.py` летает и шлёт позицию/находки на панель.
5. **Стоп** → `pkill a8gem.py` на обоих.
6. **Тест-лог Д1/Д2** → SSH + `board_run.sh drone_ping.py` (без полёта): связь, телеметрия, батарея, кадр. Результат — карточка в логе сайта.

Кнопка «Скачать matrix.json» — запасной ручной путь. `push_mission.sh` — то же копирование без кнопки.

## Файлы run2

| Файл | Зачем |
|---|---|
| `ui_server.py` | HTTP-панель, API, старт/стоп/пинг |
| `index-v2.html` | сетка, пути, логи, кнопки (без Kaspersky и roslib) |
| `start_flight.py` | scp/ssh, retry при Connection reset |
| `board_run.sh` | source ROS / docker exec sverk |
| `a8gem.py` | полёт + OpenCV цветов |
| `plan_paths.py` | деление карты, два маршрута |
| `drone_ping.py` | пинг борта на сайт |
| `ui_report.py` | POST на панель |
| `mission_log.py` | `logs/*.log` |
| `matrix.json` | карта 5×5 + `drone1`/`drone2` `[x,y]` |

Корень JSON: `1` летать, `-1` деление. Планировщик сам режет зоны; `0` в старых файлах тоже летабельно.

Координаты: клетка ArUco `(x,y)`; map = `aruco * 0.75 - 1.5` (симулятор). Сайт: `y=0` верхний ряд.

## Известные ямы (на 2026-10-30)

1. **Bare `python3` на плате → `ModuleNotFoundError: sverk_interfaces`.** Лечится `board_run.sh`. Если и после этого нет модуля — контейнер не запущен (`docker ps` должен показать sverk).
2. **`kex_exchange_identification: Connection reset by peer`.** Плата ещё не подняла sshd / сеть. Повтор через пару секунд часто проходит. В `start_flight.py` есть retry.
3. **Батарея `-- В` на сайте**, пока нет полёта/пинга с полем voltage. Сверх часто отдаёт `/fmu/out/battery_status`, не `get_telemetry().voltage`.
4. **favicon.ico 404** — безвредно.
5. **Тест-лог раньше был фейком в JS.** Сейчас реальный SSH. Перезапускать `ui_server.py` после правок.
6. Рой ESP-NOW (`comand.md`) в полётный скрипт ещё не вшит: каждый борт летает независимо по своей зоне.
